# 💼 Gibbon - Web3 Dashboard | Готовый проект к продаже

## 📋 Описание проекта

**Gibbon** — это полностью функциональный Web3 Dashboard для работы со смарт-контрактами. Проект представляет собой современное веб-приложение на React + TypeScript с полной интеграцией блокчейна.
